# UV Robot: Autonomous Disinfection Prototype for Hospitals

### Project Overview
The UV Robot is a comprehensive prototype developed to automate and enhance disinfection processes within hospital environments. This autonomous mobile robot utilizes ultraviolet (UV) light to efficiently disinfect rooms and high-touch surfaces, aiming to reduce healthcare-associated infections (HAIs) and minimize human exposure to both pathogens and harsh chemicals.

### My Role: Technical Advisor (thesis project)
I was the technical advisor of this thesis project, guiding the team through the system design and the autonomy stack:

*   **Hardware Design & Integration:** Guidance on selecting and integrating the mobile base, UV-C lamp arrays, sensors and control units.
*   **Software Architecture:** Review of the core software stack for robot control.
*   **Application Layer:** Feedback on the interface that lets hospital staff start and monitor disinfection cycles.
*   **Autonomous Navigation:** Technical guidance on mapping, path planning and obstacle avoidance so the robot moves safely without human intervention.
*   **Implementation:** Support during the transition from simulation to the physical prototype.
